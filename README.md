This project predicts future sales trends using historical sales data using Microsoft Power BI.

- Microsoft Power BI
- Microsoft Excel

## Dataset

- Product
- Sales
- Profit
- Region

## Features
- Data Cleaning
- KPI Cards
- Line Chart

- Sales Trend Analysis
- Forecasting Future Sales
